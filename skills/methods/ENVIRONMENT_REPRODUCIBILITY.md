## Full-Dataset Rule

Before launching all-sequence jobs, every method selected for full-dataset
execution should have:

- An explicit Slurm script using either `torch_env` or a named dedicated env.
- A frozen env export or package snapshot.
- The exact checkpoint path and download/source URL.
- For any checkpoint or external asset that cannot be downloaded automatically, the method record must list the source URL, expected filename, expected local path, and a direct request for the user to download it manually.
- A note for all code patches applied to third-party repos.
- The validated GPU partition: A100, H100 fallback, or CPU.
- Whether the method is a positive candidate, negative baseline, or paper-review hold.
