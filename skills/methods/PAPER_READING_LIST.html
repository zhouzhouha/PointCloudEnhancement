Point Cloud Enhancement Paper Reading List

Generated for the UVG-CWI-DQPC OrangeKettlebell benchmark. Focus first on methods that gave negative or mixed results, because these need a paper-based decision before inclusion, exclusion, or rerun.

Current rule: benchmark scope is point-cloud-only enhancement, degraded point cloud in and enhanced point cloud out. Multimodal, partial-completion-only, and legacy TensorFlow methods should be marked separately unless you decide they are needed for survey coverage.

Priority 1: Negative Or Mixed Results To Decide

Method Year Paper / Code Benchmark Status Why Read
Pointfilter
denoising/filtering		 2020
IEEE TVCG		 repo selected-10 negative Accuracy improved, but completeness, Chamfer, recall, F10/F20, projection SSIM, LPIPS, and PCQM dropped. Read to decide whether this is expected from its filtering objective or a mismatch with dense human captures.

denoisingresampling		 2022
IEEE TPAMI		 repo smoke negative Frame 0000 had only tiny accuracy gain but worse completeness, Chamfer, recall, and all F-scores. Read before deciding whether it should remain a smoke-only negative case.

denoising		 2021
ICCV		 repo selected-10 mixed/candidate Geometry improves accuracy/F-scores but worsens completeness. Read to explain why score-based denoising can clean points while losing coverage.

ECCV		 paper / repo smoke mixed/negative You already read this paper. Keep it on the decision list because theory is relevant, but UVG smoke metrics are not strong. Full170 ablation was requested separately.
IterativePFN
filtering		 2023
CVPR		 repo smoke negative You already read this paper. It worsened all reported frame-0000 geometry metrics, so decide whether to cite as a relevant filtering method but exclude from selected-10 expansion.
PUDM
upsamplingdiffusion		 2024
CVPR		 repo selected-10 mostly negative geometry You already read this paper and marked it suitable. Geometry worsened on completeness, Chamfer-L1/L2, F10, and F20, while texture/perceptual was more positive. Decide how to explain diffusion upsampling mismatch on dense UVG scenes.
Neural Points
arbitrary upsampling		 2022
CVPR		 paper / repo selected-10 mixed/positive You already read this paper and marked it relevant. It improves completeness/F10/F20 but worsens accuracy and Chamfer-L2. Keep clearly labeled as a fixed-size 2048-input patch/object-domain adaptation.
SPSR
traditional reconstruction		 2013 project selected-10 mixed Clean face but separated blobs near human edges. Read only if you want a traditional reconstruction explanation for edge artifacts and surface closure assumptions.
