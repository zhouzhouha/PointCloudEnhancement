Final Point Cloud Enhancement Papers To Check

Updated 2026-06-23 for the UVG-CWI-DQPC OrangeKettlebell selected-10 benchmark. This is the canonical merged reading list; the older dated duplicate has been removed. Scope: point-cloud-only enhancement, degraded point cloud in and enhanced point cloud out.

Current decision: the table below is the working Final 20 list for point-cloud-only enhancement benchmarking. It combines denoising, color/texture enhancement, upsampling, joint upsampling/cleaning, and compression-derived enhancement methods with selected-10 evidence. SuperPC and FBNet remain excluded by scope; TULIP has been removed because it is LiDAR range-image upsampling, not direct point-cloud enhancement for dense RGB point clouds.
